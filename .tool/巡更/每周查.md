# 每周查

日志归档 + 漏料扫描 + 语义缺口 + 差距映射 + 碰撞扫描 + 深度维护。

> 详细流程见 `技能/health.skill.md`（体检流程）+ `技能/search.skill.md`（搜索流程）。

## 约束

- L1 自动修复: wikilink 死链、清单/回链不一致 → 自动修复
- L2 只扫不修: 回链遗漏、语义缺口 → 只报告
- L2 延迟闭环: 品级不匹配已 ⏳≥1 周 → 自动修正
- 对账.md 可写入（语义缺口新增 + L1 修复）
- 语义探针结果直接加内联链接

## 执行步骤

### 1. 日志归档

```bash
python .tool/scripts/clean_log.py
```

追加归档标记行。日志只保留最近 7 天。

### 2. 扫描原料漏料

```bash
# 无处理状态（递归搜索子目录，用 grep -r 避免 globstar 兼容问题）
grep -rL "^处理状态:" /c/Obsidian仓库/edrc/灵台/原料/ --include="*.md" 2>/dev/null

# 待提炼（递归搜索子目录）
grep -rl "^处理状态: 待提炼" /c/Obsidian仓库/edrc/灵台/原料/ --include="*.md" 2>/dev/null
```

待提炼超 7 天 → 列入超期清单。

### 3. 提取对账缺口 + 推迟追问

读 `体检/系统/对账.md` 所有 ⏳ 缺口:
- 已解决 → 改标 ✅ 已修
- 仍存在 → 统计持续时间，标注"僵持 X 周"
- 品级缺口 ⏳≥1 周且修正建议未变 → 自动修正 + 改标 ✅

### 4. 语义缺口检测

扫本周新增丹房页，提取频繁出现但无独立页的概念。记入 `体检/系统/对账.md`:
- 状态: ⏳ / ✅
- 概念: 缺口名
- 出现位置: 哪些页面提到
- 建议: 创建辐页还是追加到已有页

### 5. 差距映射

**A. 缺失概念页** — 出现≥3次但无独立页面的概念 → 记入对账
**B. 占位页升级** — `状态: 占位` 的页面，检查近期有无新原料
**C. 来源缺口** — 原料数量≥3但状态仍待提炼 → 列出
**D. 反链对账** — 遍历原料 `→ [[丹房/...]]` 回链，对比清单:
  - 原料已提炼缺回链 → 遗漏来源
  - 回链格式错误 → 编码问题
  - 清单有回链无 → 死链/虚构链接
  - 回链有清单无 → 遗漏来源
**E. 品级对账** — 下品=单源摘要，中品≥1条交叉引用，上品≥3页内联引用 → 不匹配记入对账

### 6. 记忆银行深度维护

1. **记忆银行健康检查 + 自动归档**：
   ```bash
   cd /c/Obsidian仓库/edrc/灵台/.tool/lingtai-kb
   python -c "
from memory_bank.bank import MemoryBank
mb = MemoryBank()
stats = mb.stats()
if stats['pending'] > 20:
    from memory_bank.decay import DecayScheduler
    de = DecayScheduler(mb)
    result = de.run()
    stats = mb.stats()
    print(f'AUTO_ARCHIVED:{result[\"archived\"]} PROMOTED:{result[\"promoted\"]}')
print(f'pending:{stats[\"pending\"]} active:{stats[\"active\"]} archived:{stats[\"archived\"]}')
"
   ```
   - pending > 20 → 自动调 `DecayScheduler.run()` 归档低置信度 + 晋升成熟候选
   - **pending 动态基线告警**：调 `python .tool/scripts/pending_baseline.py`，仅当输出 `alert=true` 才输出 🔴 警告

2. `mcp__lingtai-kb__memory_stats` — 输出记忆银行全量统计
3. `mcp__lingtai-kb__memory_scan_conflicts` — 扫描记忆冲突对
4. 无冲突 → 静默通过。有冲突 → 记入周检报告「记忆冲突」段

### 7. 知识缺口检测

`knowledge_gaps` 扫描原料中待提炼且丹房无对应条目的内容，指导本周选料。

```bash

knowledge_gaps()
# 按域筛选
knowledge_gaps(domain='00-思考与认知')
```

有严重缺口（severity≥0.7）→ 记入报告纳入本周提炼计划。

### 8. 决策信号复审

从 `observation_engine.check_decision_signals()` 获取本周信号状态，扫描 pending 决策。

判断规则：
- `signals_triggered` > 0 → 本周有信号触发，建议优先复审
- 自动归档条件：`last_verified` > 14 天前 且 `current_confidence` < 0.4 且非 `[已确认]` 标签
- 归档后仍有 pending 决策 → 列出清单供复审
- 归档后无 pending → 静默通过

### 9. 图谱缺口周趋势

```bash
cd /c/Obsidian仓库/edrc/灵台/.tool/lingtai-kb
python -c "
from reflect_engine import ReflectEngine
r = ReflectEngine()
gaps = r._check_graph_gaps()
invisible = [g for g in gaps if g.type == 'graph_gap' and '不可见' in g.topic]
deadend = [g for g in gaps if g.type == 'graph_gap' and '死胡同' in g.topic]
isolated = [g for g in gaps if g.type == 'graph_gap' and '孤立' in g.topic]
print(f'本周图谱缺口：不可见{len(invisible)} 死胡同{len(deadend)} 孤立{len(isolated)}')
"
```

**处理策略**（L2 只扫不修）：
- 每周出一次趋势（增/减/持平），记入周检报告
- 连续 3 周增长 → 强烈建议安排手动修复会话
- 单周波动 < 5% → 正常波动，静默不报

### 11. 知识自动演化

`auto_evolve` 扫描全库→自动建联（补链）+ 近重复互链 + 产出内容刷新候选 + 概念碰撞扫描。全全自动，git 提交即回滚点。

```bash
# 先 dry-run 预览
auto_evolve(dry_run=True, budget=5)
# 确认后跑真
auto_evolve(dry_run=False, budget=5)
```

**概念碰撞处理（灵识逐条判断）：** `auto_evolve` 返回的 `collision_candidates` 包含跨域语义相似碰撞对。灵识逐条评估：

| 类别 | 判定 | 处理 |
|------|------|------|
| A: 已知关系 | 同域/同系列/工程文档间的已知引用 | 跳过 |
| B: 值得补链 | 跨域真实关联，但不需要新页面 | `page_add_link` 加双向链 |
| C: 真正意外 | 跨域意外关联，值得提炼为新知识 | `page_create` 新建跨域桥接页 |

执行：`concept_collide(top_n=20)` → 逐条判断 → 分类处理。跳过理由记录在日志中。
