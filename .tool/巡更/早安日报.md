# 早安日报

## 执行步骤

### 1. 预取数据

```bash
python .tool/scripts/fetch_briefing_data.py
```

输出: `.tool/cache/briefing/YYYY-MM-DD.json`

### 2. 读预取数据

读 `.tool/cache/briefing/YYYY-MM-DD.json`，字段: weather / aihot_items（原始·精选流）/ aihot_lead / daily_sections（原始·日报分类）/ daily_flashes / **ai_news（已合成·直接用于输出）** / news_60s / motto / token_yesterday / tool_calls_yesterday

### 3. 降级模式（缓存不存在时）

- aihot: `curl -sH "User-Agent: ..." "https://aihot.virxact.com/api/public/items?mode=selected&take=10" | jq '.items[:3]'`
- 天气: `curl "wttr.in/Xinghua?format=%C+%t&lang=zh"`

### 4. 扫描灵台待办

- 读 `作品/选题池` → 待写选题数量 + 列表
- 随机金句: `grep "> \*\*金句\*\*" 丹房/ --include="*.md" | shuf -n 1`

### 5. 格式化输出

模板:
```
☀️ 早上好，老陈。

今天是 {YYYY年MM月DD日}，{星期X}（{lunar_date}）。
{weather}

━━━ 今日 AI 圈 ━━━
{aihot_lead（为空则跳过此行）}

━━━ AI 资讯 ━━━
（直接遍历预取数据里的 `ai_news` 数组——脚本已按"日报分类骨架优先 + 精选热度补缺 + permalink 去重"合成好 5-7 条，跨分类天然铺开。顺序输出即可，不重排、不二次去重（脚本已完成）。
 每条格式如下：）

模板（每条）：
```
{N}. **[标题](链接)** — 一句话摘要
   🏷️ {section}（日报分类名，或"精选"）
   {hot_score 非空时加一行：🔥热度 {hot_score}}
   > 为什么值得看：{短评拉回到老陈最近关注的方向——灵识/零台/含人量/公众号/一人公司/认知系统/内容创作等，选最贴合的，不是每次都含人量。不讲泛泛行业判断。}
```

━━━ 快讯 ━━━
（daily_flashes 有数据时输出，选 2-3 条，一句话一条。
  daily_flashes 为空时跳过此段。）

━━━ 综合资讯 ━━━
（news_60s 选 5 条；尽量覆盖不同领域——社会/财经/科技/体育/文娱各来点，别 5 条挤同一类。
 有 news_60s_link 时，段末附一行「📖 [60s 早报全文](链接)」。）

━━━ 灵台待办 ━━━
📝 选题池：{N} 个待写
🪙 灵台输出：昨日 {calls} 次调用，约 {tokens_k}K tokens 有效数据馈入 AI

━━━ ━━━
{motto}

要开始干活吗？我在这儿。
```

### 6. 保存

写入 `.tool/hook-summaries/YYYY-MM-DD.md`

### 6b. 选题参考（新增）

在完成上述格式化输出后，额外执行以下搜索与产出：

**搜索**（5 组 WebSearch）：
   - 小红书 今日热点 热门话题
   - 抖音 今日热点 热搜榜
   - 自媒体运营 最新趋势 技巧
   - AI 内容创作 最新工具 动态
   - 认知思维 独立思考 深度思考

**格式化为选题参考段**，放在早安日报正文末尾（灵台待办之后、motto 之前）：
```
━━━ 📌 今日选题参考 ━━━

🔥 今日热点
（抖音/小红书热榜 Top 话题，每条附 1-2 句切入建议）

💡 运营灵感
（自媒体运营趋势、技巧，附可复用的方法公式）

🤖 AI 动态
（AI 内容创作新工具/新趋势，拉回到老陈的关注方向）

🧠 思维补给
（认知思维相关内容，可作为深度选题素材）
```

**额外写入**：将选题参考段单独写入 `简报/选题参考-YYYY-MM-DD.md`（只写选题参考段本身，不含早安日报其他内容）。

### 7. 自检

| 检查项 | 方法 | 异常动作 |
|:------|:-----|:---------|
| 预取数据 | json 文件存在且含有效字段 | 缺天气→跳过天气段；缺 ai_news→跳过 AI 资讯段；全缺→输出纯问候+待办 |
| 降水概率 | 各数据段+待办段均命中产出模板 | 缺段→在日志标注「${段名}段缺失」 |
| 选题池存量 | 记录今日待写数，明日对比 | 不阻塞，仅记录 |
| URL 精确性 | 逐一检查各链接无重复段、拼写错误 | 发现错误→修正后输出，并在日志标注 |
| 计数一致性 | 选题池"X 个待写"与实际列表条目数对齐 | 不一致→修正后输出 |
| 完整性 | AI 资讯覆盖 ai_news 全部条目，无漏条、无重复（去重已在脚本完成） | 漏条→补全后输出 |
| 编号格式 | 选题池编号统一用空格分隔（`#27 AI` 不是 `#27-AI`） | 格式不一致→修正

## 约束

- 仅输出一次，不重复
- 不用套话（综上所述/值得注意的是）
- 待办为零 → 「今天没什么积压的，可以轻装上阵」
- 双源全挂 → 仍输出问候 + 待办
- 天气失败 → 跳过，不阻塞
- **日报全文内联输出至消息体**（手机端微信推送不附带文件），不得仅写"详见文件"或依赖 present_files

## 数据字段

| 字段 | 说明 | 降级 |
|:----|:-----|:-----|
| weather | 今天天气摘要（概况 + 温度范围 + 降雨信息） | 跳过天气段 |
| aihot_items | 精选流原始条目（score/category 字段齐全） | 原始输入，`ai_news` 由其与 `daily_sections` 合成；两源皆空→跳过 AI 资讯段 |
| aihot_lead | 主编点评（daily.lead.leadParagraph，常为空） | 为空时跳过，不输出占位行 |
| daily_sections | 日报分类原始条目（label + items，无 score） | 原始输入，`ai_news` 的分类骨架来源 |
| daily_flashes | 快讯（短平快，无摘要） | 为空时跳过快讯段 |
| **ai_news** | **合成后的 AI 资讯候选（5-7 条，已去重、带 section + hot_score）** | **AI 资讯段唯一数据源，直接遍历输出** |
| news_60s | 15 条综合新闻 | 跳过综合资讯段 |
| motto | 每日微语（源：60s 接口 `tip` 字段；丹房 `> **金句**` 为备用） | 为空时跳过金句段 |
| lunar_date | 农历日期（60s 接口） | 为空则不显示在问候行 |
| news_60s_link | 60s 早报全文微信链接 | 为空则不附全文链接 |
| token_yesterday | 灵台 LLM Token 统计 | 忽略，改用 tool_calls_yesterday |
| tool_calls_yesterday | 工具调用计数（sessions/calls/data_chars/data_tokens） | 跳过工具调用行 |
