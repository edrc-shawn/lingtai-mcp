# 预取简报

## 定位

为「早安日报」（08:20）提前拉取外部数据。日报不自己做 HTTP 调用，只读缓存。

## 步骤

```bash
cd C:\Obsidian仓库\edrc\灵台
python .tool/scripts/fetch_briefing_data.py
```

## 输出

`.tool/cache/briefing/YYYY-MM-DD.json`，包含：

| 字段 | 来源 | 说明 |
|:----|:-----|:-----|
| weather | wttr.in | 今天逐时预报 + 摘要 |
| aihot_items | aihot.virxact.com | 精选 AI 资讯（top 6） |
| aihot_lead | aihot.virxact.com | 主编点评 |
| daily_sections | aihot.virxact.com | 按分类组织的条目 |
| daily_flashes | aihot.virxact.com | 快讯 |
| news_60s | 60s.viki.moe | 15 条综合新闻 |
| motto | 60s.viki.moe | 每日微语 |
| tool_calls_yesterday | tool_sessions.jsonl | 灵识工具调用计数 |

## 降级

所有外部源均有缓存回退。全挂时输出空结构 + errors 列表，不阻塞日报。

## 性能

约 3 秒（首次 ~6 秒），设 08:10 执行，日报 08:20 读缓存即可（避开 aihot 每日 08:00 digest 翻面临界）。
