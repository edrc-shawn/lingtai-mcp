# 每日检

Lint + 反链追加 + 缺口检查 + 选题捕获 + 灵识自检 + 巡更自检。

> 详细流程见 `技能/health.skill.md`（体检流程）+ `技能/system.skill.md`（系统操作流程）。

## 约束

- L1 自动修复: 格式错误、死链接、反向链接缺失 → 自动修复 + 报告
- L2 只扫不修: 孤立页、内容腐烂、语义漂移、Obsidian 图谱缺口 → 仅输出报告
- 不写对账.md（对账.md 由 AI 在提炼/修复时写入）

### 2. 提取 24h 变更

从缓存读取（不再单独调 git log）：
```bash
python -c "from git_log_cache import load; c=load(); print(f'Commits: {c[\"summary\"][\"total_commits\"]}'); [print(f'  {f}') for f in c.get('changed_files',[])]"
```

列出新增丹房页 + 大修改页面（变更量 > 30%），检查矛盾信号。

### 3. 反向链接追加

对 24h 新页中枢纽页/独立概念页执行:
1. 判断是否需做反链（跳过薄页/辐页/纯数据页）
2. 提取主题词/标签
3. grep 全库找相关已有丹房页（目标 5-10 条）
4. 对每个候选旧页，在内容相关段落用内联 `[[链接]]` 自然引用新页
5. 不追加 `## 推荐阅读` 区块
6. 旧页无自然交叉点 → 跳过

### 4. 对账面板同步

1. 运行 lint（步骤1）获取断裂链接列表
2. `mcp__lingtai-kb__health_ledger(action='read')` — 获取当前活跃缺口
3. **新增缺口**：lint 缺口不在健康账本活跃列表 → 通过 MCP 工具 `health_ledger` 追加（禁止直接编辑对账.md 文件，会破坏 YAML frontmatter）
4. **关闭已修**：健康账本活跃缺口不在 lint 输出 → `mcp__lingtai-kb__health_ledger(action='close', gap=缺口名, status='已修')`
5. lint 无缺口且活跃已清 → 标注「对账面板：✅ 清空」

### 5. 选题捕获（双线并行）

#### 线 A：公众号选题

检查 24h 变更中是否有符合公众号选题标准的素材（个人经历/真实体感/反转洞察至少占一）。符合 → 追加到 `作品/选题池`。

#### 线 B：追问捕获

捕获触发深度追问的系统级变更。命中 → 追加到 `作品/追问池`。

**信号敏感度:**

| 级别 | 条件 | 动作 |
|:--|:--|:--|
| 🔴 高 | 工具翻倍/规则重构/新抽象层/核心页翻倍 | 必须捕获 |
| 🟡 中 | 新增自动化/文档分类/页面重命名/格式变更（命中≥2） | 建议捕获 |
| 🟢 低 | 配置调整/连续3天变更/单文件5+commit（命中≥3） | 可选捕获 |

**追问格式:** `| 序号 | 追问 | 敏感度 | 信号源 | 创建日期 | 状态 |`

### 5.10 会话外发现（P3 贾维斯差距）

用户不在线时，自动扫描知识库发现潜在问题，写入记忆银行供下次会话主动报告。

**操作**：
1. 调 `concept_collide(min_similarity=0.65, max_similarity=0.75, top_n=5)` 扫描意外跨域关联
2. 调 `knowledge_gaps(min_severity=0.5)` 扫描高优先级待提炼缺口
3. 调 `lifecycle_scan(stale_days=60, min_backlinks=1)` 扫描可清理的陈旧页

**写入条件**：只写入置信度高于 0.65 的发现，避免噪音。
```bash
# 伪代码逻辑
# 发现意外关联 → memory_write(tags=["巡更发现", "跨域关联"], content="...", expected_consumer="reasonix")
# 发现高优先级缺口 → memory_write(tags=["巡更发现", "知识缺口"], content="...", expected_consumer="reasonix")
# 发现可清理页 → memory_write(tags=["巡更发现", "生命周期"], content="...", expected_consumer="reasonix")
```

**自保**：同类型发现 7 天内不重复写入（查 `memory_search(tags=["巡更发现"], keyword={类型})` 最近 7 天有无同款）。

检查当日各巡更任务的产出的完整性。数据源: 今日 hook-summaries + git log + 本报告。

- 记忆银行归档连续 3 天增长 → 检查衰变策略与 DECAY_POLICIES
