# 三通道共识协议

跨域复杂问题走三通道独立查询 + 交叉对比，取代单通道检索。

## 触发条件

同时满足以下条件时默认触发：

- 用户问题涉及**两个及以上知识域**（如域00认知 + 域07AI、域00 + 域05哲学）
- 或用户要求"验证""确认""比较""分析"
- 或系统对单通道检索结果的置信度存疑（如 search 命中少、graph 扩散结果分散）

纯事实查询（"今天几号""xx的概念是什么"）不需要走共识协议。

## 协议流程

### 第一步：三通道独立查询

三条通道并行执行，互不知晓对方结果：

| 通道 | 工具 | 覆盖范围 | 盲区 |
|---|---|---|---|
| A — 文本检索 | search(keyword, search_content=true) | 灵台知识库全文（标题+摘要+正文） | 语义变体、同义表达、未被文本覆盖的隐式关联 |
| B — 图扩散 | graph(start_page, hops=3, weighted=true) | Hebbian关联网络 | 外部知识、灵库未收录概念 |
| C — 外部联网 | tavily_search(keyword, max_results=5) | 互联网学术/技术/新闻 | 深度框架性知识、精度 |

关键词策略：三通道可以使用略有差异的关键词（A/B 偏灵台内部用语，C 偏外部通用用语），以匹配各通道的语料特性。

### 第二步：交叉对比

将三通道结果按以下维度对比：

**共识**（多通道一致支持）：
- 哪些结论/信息在两路及以上通道中出现
- 标记为高置信度，优先输出

**分歧**（单通道特有）：
- 通道A特有但B/C无 → 可能是"灵台专有知识，外部无覆盖"
- 通道B特有但A/C无 → 可能是"关联网络发现的隐式连接"
- 通道C特有但A/B无 → 可能是"外部新信息，灵库未收录"
- 每条分歧标记来源通道，不静默合并

**检索记录**：
- 每条通道的执行情况（命中数、关键结果摘要）
- 供用户追溯

### 第三步：输出格式

```
## 三通道共识输出

**问题**：[用户问题]

### 检索记录
| 通道 | 工具 | 结果数 | 覆盖 |
|---|---|---|---|

### 共识（多通道一致）
- [结论A] ✅（A+B+C / A+B / B+C）

### 分歧（单通道特有）
- [结论B] 🔵（仅A通道 — 灵台专有）
- [结论C] 🟢（仅C通道 — 外部新信息）

### 整体评估
[综合判断]
```

## 与现有工具的关系

共识协议**不新增任何 MCP 工具**，只改变现有工具的编排方式。对应 AGENTS.md 规则⑤（三步检索管线），共识协议是其增强变体——用三通道替代单通道检索，适用于复杂问题。

## 限制

- 外部通道（Tavily）月限1000次，高频场景慎用
- 图扩散在大知识库中可能返回大量弱关联节点，hops=2 或加 weighted 过滤可降低噪音
- 三通道结果对比需要 LLM 判断力，本身可能引入新的"共识幻觉"（如错误地认为两通道结果一致）
