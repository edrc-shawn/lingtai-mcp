# 视觉风格 DNA

> 一篇内所有图必须视觉统一。

## 六维统一

| 维度 | 规则 |
|:-----|:-----|
| 背景 | 纯白，不要纸纹/米色/阴影/渐变 |
| 线条 | 黑色手绘墨线，不光滑，不闭合完美 |
| 色彩 | 黑色70% / 红橙色30%，颜色引导视线不填满 |
| 角色 | 同一角色同一外观，锚点图锁定 |
| 质感 | 纸盒质感，手绘不规则边缘，轻微褶皱 |
| 情绪 | 平静中性为基底，根据文章情绪微调，禁止夸张 |

## 颜色面板

| 部位 | 颜色 | 说明 |
|:-----|:-----|:-----|
| 身体（纸盒） | 黑色/深灰 #333 | 主色 |
| 眼镜框 | 黑色 | 固定色 |
| 手持物/关键配件 | 红色 #D32F2F / 橙色 #E65100 | 引导视线 |
| 背景 | 纯白 | 留白 |
| 线条 | 黑色 | 墨线 |

## 红线

- 不要水彩/渐变色/浓重铺色
- 不要卡通/可爱/萌
- 不要光滑/完美/对称
- 角色不能当装饰——必须参与核心动作
