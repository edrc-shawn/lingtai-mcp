# 反 PPT 自检

> 生图后逐张过 checklist。QA 不通过 → 重生成，不要"带着问题交付"。

## 生图前预检（步骤6）

```
□ 角色是画面主角吗？ → 不是就重写
□ 颜色有吗？ → 纯黑白就重写
□ 有"方框""箭头""连线"这类描述词？ → 有就重写（让角色用动作隐喻）
□ 锚点图传了吗？ → 没传 img2img 不开 API
□ 最后加了防偏可爱后缀？ → 没加就不能发 API
□ 灵魂话写了吗？ → 没写回去补深层提炼
□ 比例和prompt方向词联动？ → 没联动会变形
```

三条过不去就回炉改 shot list，不烧 API。

## 生图后 QA（步骤8）

```
□ 白底？ → 有纸纹/米色/阴影 → 重生成
□ 耳东在做真实动作？ → 只是站着当装饰 → 重生成
□ 只讲一个核心结构？ → 塞了太多东西 → 重生成或裁
□ 新隐喻？ → 和旧图构图重复 → 重生成
□ 没有PPT感？ → 像信息图/流程图直接截图 → 重生成
□ 中文标注≤8个字？ → 太多文字 → 删减或重生成
□ 耳东占对了比例？ → 解释图太大/情绪图太小 → 调prompt重生成
□ 没有卡通/可爱倾向？ → 偏萌 → 加防偏后缀重生成
```

## 失败信号速查

| 问题 | 迭代方向 |
|:-----|:---------|
| 太PPT | 加荒诞隐喻，去掉方框箭头 |
| 太复杂 | 删节点，只留核心结构 |
| 太可爱 | 加防偏后缀，强调纸盒质感 |
| 构图重复 | 发明新隐喻，换结构类型 |
| 角色太小/太大 | 调占比，解释图压小情绪图放大 |
