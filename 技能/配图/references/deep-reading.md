# 深层提炼

> 理解文字背后的含义，不是图解表面。每张配图必做，不能跳。

## Q0 文体制导（全文层）

先看清这篇是什么文体，定全文主张该画什么，再往下逐点深挖。

按文体查"该 hero 什么"：

| 文体 | 全文主张画什么 | 别误当主图的诱饵 |
|------|---------------|-----------------|
| 产品发布 | 新角色/能力跃迁 | 某个benchmark、某段demo |
| 复盘/事故 | 失败的前提或断掉的环 | 某一个具体事故 |
| 观点/金句 | 这主张推翻的那个东西 | 话题的中性描绘 |
| 教程/How-to | 它带来的转变（前后差） | 把每个步骤平铺当主图 |
| 评测/对比 | 跨过的那道阈值/反差 | 一张通用跑分表 |
| 故事/轶事 | 那个顿悟瞬间 | 把事件流水当主图 |

**判据**：写完主张的"灵魂话"，问一句"这是全文的活，还是某段的活？"——是某段的 → 你抓的是支撑机制，回来重锁。

## 三问提炼（逐锚点）

| # | 问题 | 填什么 |
|:-:|:-----|:-------|
| 真意 | 作者真正想说什么？（不是段落标题，是背后的意思） | 一句话 |
| 张力 | 这里的冲突/反转/意外是什么？（期望 vs 现实 / 大 vs 小 / 快 vs 慢） | 一个对比 |
| 灵魂话 | 这张图的一句话灵魂——读者看完会记住的那句 | 一句话（写进 shot list） |

**实操技巧**：
- 问"所以呢"：段落说"Codex有500万周活"——所以呢？→ 画"全民平台"比画"500万"有意思
- 问"反过来呢"：以前是怎样的？→ 画"以前"和"现在"的反差
- 问"谁最痛"：对谁影响最大？→ 画那个人的状态
- 问"哪个细节最反直觉"：抓住它放大，其他的缩小

## Q4 必现内容清单

从原文 grep 出这张图非画不可的真实部件/数字/步骤——保证准确，不被隐喻带偏。

- **解释图**：列出它要呈现的真实部件，一个不能少
- **数字/术语**：必须是原文真值（45.6%就写45.6%，不能凑整）
- **隐喻图**：列出隐喻每个物件对应机制的哪个真实部件

## 双重约束

- **灵魂话**决定读者记住什么
- **必现清单**保证不误导

两个都做完才进入下一步。
