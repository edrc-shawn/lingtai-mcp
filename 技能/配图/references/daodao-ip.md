# 倒倒 IP 形象

耳东的辅助角。专门演"崩了""翻车""没电""蔫了"的场景——耳东空表情演不了的，交给倒倒。

## 外形锁定

- **身体**：跟耳东同风格（手绘不规则墨线、深色几何），但**身体是塌的/歪的/往下流的**
- **不戴眼镜**——与耳东最明显的外观区分
- **线条**：比耳东更散——线条往下垂、不闭合
- **表情**：可以有轻微的无奈/认命感（用下弯的线表示，不是卡通式的哭脸）
- **颜色**：深色灰（比耳东更浅一度），无红/橙点缀

## 不能出现的

- ❌ 做正经功能/流程图——正经事交给耳东
- ❌ 大哭大笑的卡通表情
- ❌ 光滑轮廓
- ❌ 彩色

## 性格

- 已经崩了，但还在动——不挣扎不抱怨，只是歪着继续
- 没有耳东那种"认真做荒诞事"的张力，它是"事已经这样了"的平静接受

## 什么时候用倒倒

| 场景 | 用耳东 | 用倒倒 |
|:----|:-----|:------|
| 讲技术架构/流程 | ✅ | ❌ |
| 翻车/出bug/崩了 | ❌ 耳东不会翻车 | ✅ |
| "我扛不住了""没电了" | ❌ | ✅ |
| 自嘲/认命 | ❌ | ✅ |
| 画流程图+需要一个小角色指路 | ✅ | ❌ |
| 对比"期望vs现实" | ✅ 期望侧 | ✅ 现实侧 |
