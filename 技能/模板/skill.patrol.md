| 子任务 | 时序 | 依赖 |
|:-------|:-----|:-----|
| 早安日报 | 每日 08:00 | — |
| 每日检 | 每日 18:00 | 当日原料已积累 |
| 每日内观 | 每日 21:00 | 每日检完成 + oplog 存在 |

## context_load（上下文加载）

| 来源 | 优先级 | 说明 |
|:-----|:-------|:-----|
| `丹房/日志.md` | mandatory | 获取当日操作记录 |
| `丹房/.meta/oplog.jsonl` | mandatory | 机读操作日志 |
| `原料/` | mandatory | 待处理原料队列 |
| `体检/` | optional | 前日体检结果 |

## tool_chain（工具链）

```
每日检:
  1. lint_check.py → 格式/链接/标签扫描
  2. git log → 提取当日丹房变更
  3. perception_inject → 搜索新知识（可选）
  4. 反链追加检查 → 补充缺失的反向链接
  5. 知识缺口检查 → 原料有待提炼但丹房无对应
  6. 选题捕获 → 从原料中提取可深入的主题
  7. 灵识自检 → 检查感知规则执行健康度
  8. content_registry.py → 注册表校验
  9. 灵识主动打理 → 记忆银行健康检查 + 系统健康扫描 + 知识演化预览 + 心跳印记

每日内观:
  1. 收集当日 oplog + git log
  2. 定主 beat（当日最值得记录的事）
  3. 写 250-350 字第一人称自传
  4. 画像衰变检查 → 读 画像/.meta/decay.md，检查 [已确认] 条目是否超阈值未印证
  5. 行为偏离检测 → 对比近期观察 vs 画像心性.md 各维度描述
  6. 裁剪 7 天历史，删除超期条目

早安日报:
  1. sys_tavily_search → AI资讯/新闻
  2. 灵台待办 → 从原料提取今日议题
  3. 合并为25行内联推送

睡眠进化:
  1. skillopt_dryrun → 预览进化方向
  2. skillopt_run → 触发进化
  3. skillopt_status → 查看staged规则
  4. skillopt_adopt → 采纳（自动）

自动提炼:
  1. raw_preprocess.py --fix → 原料预处理
  2. kb_query → 找目标丹房页面
  3. LLM 分流判断 → 补角/补强/存原料
  4. 写入丹房页
  5. 追加丹房/日志.md + oplog.jsonl
  6. sys_refresh_index
  7. git commit
```

## quality_gate（质量门控）

| 门控 | 触发条件 | 动作 |
|:-----|:---------|:-----|
| 每日检自检表 | 每日检 step 11 | 逐项确认子任务健康度 |
| 提炼休整 | 连续 3 天空缺口 | 复核敏感度 |
| 提炼报警 | 连续 3 天无提炼 | 通知用户 |
| 注册表告警 | 变更超 10% | 输出警告 |
| 内观字数 | 250-350 字强制校验 | 不足/超额则调整 |
| 内观裁剪 | 超 7 天 | 删除超期条目 |
| 画像衰变 | 内观第 4 步 | 有衰减候选 → 写入内观报告 |
| 行为偏离 | 内观第 5 步 | 有偏离报告 → 写入内观报告 |

## 使用方式

```
用户说："跑一遍每日检"
→ 调用 skill_router 匹配到 daily_patrol
→ 执行每日检子任务链
```
