# 收尾流程惯例

> 每次完成实质性操作后执行。丹房页写操作已自动完成部分步骤。

## 收尾 11 步

### 0. 尺寸体检
检查 AGENTS.md 是否超限（≤300行 / ≤15KB）。超限则先精简。
**净增 30 行红灯**：若本轮净增 > 30 行，说明塞了叙事而非规则，退回删。

### 1. 写丹房日志（丹房页操作 → 自动）

### 2. 重建灵识索引 → `system_refresh_index`

### 3. 提 Git
- commit 前缀：`feat:`(新功能/新页) `fix:`(修 bug) `refine:`(提炼/规则改进) `docs:`(文档/内观)
- 只暂存本轮产物，不裹无关改动（禁止 `git add -A`）
- 代码/架构改动 → commit 后 push；自动化产出 → 只 commit 不 push

### 4. 波及检查（仅提炼/新建丹房页时）
→ 调 `ingest_ripple` 预览 → 逐条 `page_append_section` 补引用

### 5. 文档对齐
改了代码/流程后检查 AGENTS.md/README/丹房页是否需同步

### 6. MCP 刷新
改了 `.tool/lingtai-kb/` 代码后调 `sys_reload`

### 7. 教训归档
有教训则 `memory_write(tags=["lesson"])`。按信源分流：
- AI 自省的行为规范 → `type:behavior` 直接写高置信
- 用户教的偏好/事实 → `type:knowledge` 保持 pending 待确认

### 8. 记忆毕业检查
`memory_consolidate(min_confidence=0.7)` 查候选。
判据：下一个接手的人需要知道吗？需要 → 属丹房不属记忆，毕业。

### 9. 跨会话存档
`memory_snapshot` 存关键结论/已否决方向/待解问题。

### 10. session_end 宏
必调 `session_end(session_start=..., work_imprint=...)`。
不调 = 画像和记忆不更新。

### 11. 变更摘要
输出结构化摘要：记忆变更 · 知识变更 · 未处理事项
