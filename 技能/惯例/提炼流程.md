# 提炼流程惯例

> 从原料到丹房页的完整管线。每次提炼前读此文件。

## 完整流程（5 步）

### 1. 选料

**优先级**：新料优先，每 14 篇新料回溯 1 篇最旧料。

- 调 `raw_derive` 看原料列表
- 调 `knowledge_gaps` 看待提炼缺口
- 用 `grep` 在 `原料/` 搜 3-6 个独特短语，确认同主题命中

### 2. 前置三检（漏一不可）

1. **原料同主题检索** — `grep` 在 `原料/` 搜核心短语，命中多篇则合并提炼
2. **丹房去重** — `knowledge_search` 确认丹房有无同页
3. **内容匹配** — 确认原料自带 backlink 是否匹配目标页

### 3. 提炼执行

优先用 `refine_quick`（一步完成预检→写页→标记→建链→提交）。

不满足时手动分步：
- `page_create`（建页）→ `page_append_section`（补内容）→ `refine_mark`（收尾登记）

### 4. 波及检查

- 调 `ingest_ripple` 预览波及页
- 逐条审查后 `page_append_section` 批量补引用
- 目标：触及 **8-15 页**
- 全跳过（applied_count=0）时手动补链：读新页→列同域枢纽页→追加 2-3 条 `[[新页]]` 引用

### 5. 质检收尾

逐条打勾，缺一不可：

- [ ] 新页有入链（≥2 条来自其他丹房页，`grep -r slug 丹房/`）
- [ ] 新页有出链（≥2 条 wikilink）
- [ ] 原料标记 `状态: 已提炼`
- [ ] 索引已重建（`system_refresh_index`）
- [ ] Git 干净（`git status` 无红字）
- [ ] 去重检查（`python .tool/scripts/dedup_check.py` 无 L1/L2 命中）

## 域判定规则

以内容核心为准，不被 `raw_derive` 字面带偏：

- "阅读" → 00-思考与认知，非 08-教育
- "写作" → 01-内容创作，非 08-教育
- "投资" → 06-商业与投资，非 03-社会观察
- "AI工具" → 07-工具与AI，非 09-系统自身
