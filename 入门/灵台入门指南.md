# 灵台入门指南

> 灵台是你知识存储的地方。它有灵识，能使任何 Agent 都能秒懂你。

开始前保证两件事：Obsidian 已打开这个 vault，WorkBuddy 已安装。

---

## 一、打开就是灵台

WorkBuddy 对话窗口 → 设置工作目录为灵台 vault 根路径。

AI 会自动读规则——调 `sys_rules` 获取台律核心规范，不需要你喂任何东西。

---

## 二、放东西

看到好文章、记的笔记、跟 AI 聊出来的内容——存到 `原料/` 文件夹。

格式没要求，命名随意。AI 自动判断值不值得提炼。

---

## 三、问 AI

直接问：

```
"含人量是什么意思？"
"哲学层有哪些页面？"
"帮我梳理认知升级的几个阶段"
```

AI 先翻你的丹房，找不到再搜外部。

---

## 四、让 AI 帮你写

```
"帮我写一篇关于 AI 知识库的公众号"
"这个改成小红书版本"
"生成几张配图"
```

AI 知道你的风格——写完你瞄一眼就行。

---

## 五、MCP 配置（一句话让任何 AI 接入灵台）

复制下面这段话发给任意 AI：

```
帮我配一个 MCP Server，让当前工具能访问「灵台」知识库。

服务器文件：灵台/.tool/lingtai-kb/mcp_server.py
工具是：___
（填 WorkBuddy / MiMo Code / Cursor 中的一个）
```

AI 会自动选对格式、写入正确位置。写完去点「信任」就能用。

完成后对 AI 说一句：

```
你现在能通过灵识 MCP 工具访问「灵台」知识库。
调用 query 搜索知识，调用 search 全文搜索。
你不需要问我有什么，直接搜就行。
```

然后 AI 就可以直接查你的知识库了。

## 六、自动化（建一次就行）

WorkBuddy → 自动化 → 新建，填以下项目：

| 名称 | 时间 | 提示词 |
|:---|:---|:---|
| 巡更·早安日报 | 每天 08:00 | `按 .tool/巡更/早安日报.md 规范运行。CWD=灵台/。` |
| 巡更·每日检 | 每天 18:00 | `按 .tool/巡更/每日检.md 规范运行每日体检。` |
| 巡更·每周查 | 每周一 09:00 | `按 .tool/巡更/每周查.md 规范运行每周体检。` |
| 巡更·每日内观 | 每天 21:00 | `按 .tool/巡更/每日内观.md 规范运行每日内观。` |
| 巡更·每月问 | 每月 1 日 10:00 | `按 .tool/巡更/每月问.md 规范运行每月体检。` |

工作目录统一填：`/path/to/灵台/`

## 进阶：多 AI 协作

灵台可以被多个 AI 工具同时使用。MCP 让任何 AI 都能接入：

| 工具 | 接入方式 | 适合干什么 |
|:---|:--------|:---------|
| WorkBuddy | 打开 vault / 配置 MCP | 日常对话、问知、输出文章、跑自动化 |
| Cursor | 配置灵识 MCP | 编码时查灵台知识 |
| Claude Desktop | 配置灵识 MCP | 外部问知 |
| 任意 MCP 客户端 | 配置灵识 MCP | 查灵台知识库 |

唯一规则：**同一时间不要让两个 AI 同时改同一个页面**。
