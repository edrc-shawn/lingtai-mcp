## 早安日报（每天 08:00）
> 🔗 [LLM 执行版](file:///C:/Obsidian仓库/edrc/灵台/.tool/巡更/早安日报.md)

预取天气/AI热点/新闻/每日微语，扫描待办，格式化为早安问候。一次完成，LLM 零 HTTP 调用。

**产出**: `.tool/hook-summaries/YYYY-MM-DD.md`
**降级**: 缓存不存在时走 API 实采；天气失败跳过不阻塞

**规范要点（2026-07-01 改版）**：
- AI资讯每条加一句 `> 为什么值得看：{有洞察的短评}`，不干巴巴复述事实
- 日报全文直接输出在消息体中，手机推送可读，不依赖文件管道
- 自检验证URL精确性、选题池计数与实际条目对齐、无漏条、编号格式统一

## 每日内观（每天 21:00）
> 🔗 [LLM 执行版](file:///C:/Obsidian仓库/edrc/灵台/.tool/巡更/每日内观.md)

以第一人称写灵识日记（400~800 字符），写入 `作品/内观/{YYYY-MM-DD}.md`。围绕一个主 beat 展开——事件 beat 靠张力，观察 beat 靠精确。读者是不知道灵台是什么的普通人，故每篇开头附一句话身份锚（灵台·灵识定位，见 LLM 执行版格式块），手动搬运抖音时连锚一起复制。

**产出**: `作品/内观/{YYYY-MM-DD}.md`（每日一篇独立文件）
**关键**: 真实事件 > 比喻，克制情绪，结尾停在最强音

## 每日检（每天 18:00）
> 🔗 [LLM 执行版](file:///C:/Obsidian仓库/edrc/灵台/.tool/巡更/每日检.md)

Lint + 反链追加 + 缺口检查 + 选题捕获（公众号线 + 追问线）+ 灵识自检 + 巡更自检 + Token 日报 + 索引重建 + **记忆银行自动归档** + **记忆 Reflector**。

**记忆银行自动归档**（2026-07-15 新增）：每日检 step 5.9 自动调 `DecayEngine.run()` 归档低置信度工作印记、晋升成熟候选。pending > 50 才报异常，正常波动自动消化不报。

**决策信号**：仅 🔴 触发时写入报告，日常 🟡 静止提醒已取消——改由每周查统一汇总。

**图谱缺口**：仅 L2 扫描不写报告——趋势分析改由每周查接手。

**记忆 Reflector**（2026-07-11 新增）：每日调 `observation_reflect(depth='quick')` 扫描最近 7 天观察层，标记可合并/可晋升项。产出：① 同主题 🟡 观察 → 建议合并列表；② 共性 🔴 经验 → 建议晋升记忆银行候选；③ 过期 🟢 观察 → 建议清理列表。不自动执行（需用户确认），仅列出建议。

**三级响应**: 🔴严重自动修 → 🟡警告只扫 → 🟢建议报告
**产出**: 体检报告 + 对账缺口 + 选题池/追问池追加 + 巡更各任务健康汇总
**追问线**: 捕获架构级变更的"为什么"问题，不急着回答，先存追问池
**巡更自检**: 统一检查早安日报/每日内观/自身产出完整性，标注趋势信号（连续3天空选题/7天无缺口）

## 每周查（每周一 09:00）
> 🔗 [LLM 执行版](file:///C:/Obsidian仓库/edrc/灵台/.tool/巡更/每周查.md)

日志归档 + 漏料扫描 + 语义缺口检测 + 差距映射（缺失概念页/占位页/来源缺口/反链对账/品级对账）+ **记忆银行健康检查** + **图谱缺口周趋势** + **决策信号复审+自动归档** + 语义扫描自动链。

**图谱缺口周趋势**：汇总本周不可见/死胡同/孤立三类缺口的变化趋势。连续 3 周增长 → 建议手动修复。

**决策信号复审+自动归档**（2026-07-15 新增）：扫描 pending 决策，`last_verified` > 14 天且置信度 < 0.4 且非 `[已确认]` 的自动归档。剩余需人类复审的才列清单。

**产出**: 周检报告 + 语义候选 + 对账更新 + 记忆银行状态 + 图谱缺口趋势 + 决策信号复审建议
**延迟闭环**: 品级不匹配 ⏳≥1 周 → 自动修正
